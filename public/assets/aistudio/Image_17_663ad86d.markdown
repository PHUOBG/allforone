## Brand & Style
The design system establishes a high-performance, dark-mode competitive learning arena engineered for high-stakes problem solvers across Mathematics, Physics, and Computer Science (Toán · Lý · Tin). 

The visual language bridges the technical discipline of algorithmic platforms (Codeforces, LeetCode) with the futuristic gloss of high-tech telemetry interfaces. Rather than treating STEM subjects as dry academic textbooks, the interface frames learning as an esports-tier intellectual grind: competitive, precise, and visual.

### Visual Style
- **Aesthetic Movement:** Cybernetic Glassmorphism & High-Tech HUD.
- **Atmosphere:** Deep cosmic slate canvases layered with precision hairline borders, luminous neon status indicators, and subtle directional glow fields.
- **Tone:** Focused, elite, scientific, and gamified. Interactions feel immediate, tactile, and computationally exact.

## Colors
The color architecture relies on a specialized spectral palette calibrated for high contrast on low-light displays. Deep slate-zinc foundations eliminate ocular fatigue during prolonged analytical sessions, while tri-color photonic accents direct visual priority and delineate disciplines.

### Palette Architecture
- **Canvas Base (`#0b0f19`):** Deep abyssal slate background providing infinite contrast.
- **Elevated Surfaces (`#111827`, `#161f30`, `#1e293b`):** Progressive surface tiers for modular cards, panels, and floating consoles.
- **Primary Accent (`#6366f1` - Indigo Ray):** Applied to primary actions, interactive focus states, and the Computer Science / Informatics core domain.
- **Secondary Accent (`#06b6d4` - Cyan Plasma):** Applied to telemetry metrics, analytical graphs, real-time runtime counters, and the Physics domain.
- **Tertiary Accent (`#8b5cf6` - Violet Singularity):** Applied to Elo ranking tiers, streak meters, milestone achievements, and the Advanced Mathematics domain.
- **Structural Borders (`#1f293d`, `#374151`):** Subdued metallic hairlines that segment space without visually overpowering content.

### Gamified Elo & Discipline Mapping
- **Newbie / Unrated:** Slate (`#64748b`)
- **Specialist / Cyan:** Electric Cyan (`#06b6d4`)
- **Expert / Indigo:** Bright Indigo (`#6366f1`)
- **Master / Violet:** Royal Violet (`#a855f7`)
- **Grandmaster / Amber:** Solar Gold (`#f59e0b`)
- **Legendary / Crimson:** Hyper Red (`#ef4444`)

## Typography
The typographic hierarchy balances modern humanist geometry with developer-grade monospaced utility.

- **Plus Jakarta Sans** serves as the primary structural voice for headlines, navigational items, instructional narrative, and body copy. It provides clean geometric forms with balanced terminals that remain highly legible in saturated dark interfaces.
- **JetBrains Mono** drives mathematical formulas, raw syntax, runtime diagnostics, Elo rating integers, execution times, memory overhead figures, and tabular leaderboard data. 

### Typographic Principles
- Headings leverage slight negative letter-spacing for tight architectural solidity.
- Monospaced labels use uppercase tracking (`0.06em`) for HUD-like utility tags.
- Mathematical equations render inline using `JetBrains Mono` or dedicated TeX viewports with proportional line spacing to prevent clipping of exponents and subscripts.

## Layout & Spacing
The layout philosophy operates on an adaptive 12-column modular grid designed to accommodate multi-pane work environments: problem descriptions, LaTeX scratchpads, radar telemetry graphs, and live code execution terminals.

### Grid & Breakpoints
- **Desktop (>= 1280px):** 12 columns, 24px (`1.5rem`) gutters, 32px (`2rem`) outer margins. Supports 3-pane IDE/split-workspace layouts.
- **Tablet (768px - 1279px):** 8 columns, 16px (`1rem`) gutters, 24px (`1.5rem`) outer margins. Collapses multi-pane split screens into tabbed workspace tiers.
- **Mobile (< 768px):** 4 columns, 12px (`0.75rem`) gutters, 16px (`1rem`) outer margins. Bottom navigation bar anchors context switches.

### Spacing Rhythm
Spacing adheres to a strict 4px/8px micro-scale. Internal card padding defaults to `space-md` (16px) or `space-lg` (24px) to preserve breathability against dark-mode contrast. Element gaps inside data clusters remain compressed (`space-xs` to `space-sm`) to maximize analytical density.

## Elevation & Depth
Elevation is expressed through optical luminescence, semi-transparent frosted surfaces, and hairline illumination borders rather than heavy standard drop shadows.

### Atmospheric Tiers
1. **Canvas (Ground Zero):** `#0b0f19` solid background with subtle ambient radial gradients (`#6366f108` and `#06b6d405`) anchored to viewport corners.
2. **Glass Panels (Surface Level 1):** Background `rgba(17, 24, 39, 0.7)`, layered with `backdrop-filter: blur(12px)` and framed by a 1px border of `rgba(31, 41, 61, 0.8)`.
3. **Floating Consoles & Modals (Surface Level 2):** Background `rgba(22, 31, 48, 0.85)`, `backdrop-filter: blur(20px)`, framed by `rgba(55, 65, 81, 0.9)` with an exterior ambient aura: `0 10px 30px -10px rgba(0, 0, 0, 0.8)`.
4. **Active/Hover Focus Glows:** High-priority cards project localized diffuse glows corresponding to the discipline (`box-shadow: 0 0 20px -5px rgba(99, 102, 241, 0.25)` for Informatics, `rgba(6, 182, 212, 0.25)` for Physics, and `rgba(139, 92, 246, 0.25)` for Math).

## Shapes
The shape language implements a disciplined rounded aesthetic (`roundedness: 2`, base 8px border radius). This balances technical precision with modern software ergonomics.

- **Base Radius (`8px`):** Used on primary cards, input boxes, code blocks, and standard action buttons.
- **Large Radius (`16px`):** Used for analytical dashboard modules, telemetry widgets, and modal panels.
- **Pill Geometry (`9999px`):** Exclusively reserved for status pills, Elo rating indicators, problem tags, and filter chips to contrast against rectilinear IDE code viewports.

## Components

### Buttons
- **Primary Cyber:** Solid `#6366f1` background with white text, transitioning to a cyan-tinted glow on hover (`box-shadow: 0 0 16px rgba(99, 102, 241, 0.4)`). Active state applies a scale transform (`0.98`).
- **Secondary Ghost:** Transparent background enclosed in a 1px `#1f293d` border. Hover state illuminates border to `#374151` with faint indigo surface tinting (`rgba(99, 102, 241, 0.08)`).
- **Destructive/Terminal Action:** Semitransparent red base (`rgba(239, 68, 68, 0.1)`) with `#ef4444` border and text.

### Gamified Elo Badges & Radar Chips
- **Elo Rating Pill:** Pill-shaped badge containing user title (e.g., `CANDIDATE MASTER`), rating points in `JetBrains Mono`, and a glowing circular status indicator colored by rating tier.
- **Discipline Chips (Toán · Lý · Tin):**
  - **Toán (Math):** Violet border (`rgba(139, 92, 246, 0.4)`), background `rgba(139, 92, 246, 0.1)`, violet glyph.
  - **Lý (Physics):** Cyan border (`rgba(6, 182, 212, 0.4)`), background `rgba(6, 182, 212, 0.1)`, cyan glyph.
  - **Tin (Informatics):** Indigo border (`rgba(99, 102, 241, 0.4)`), background `rgba(99, 102, 241, 0.1)`, indigo glyph.

### Glassmorphic Problem Cards
- Constructed with `12px` roundedness, `1px` border (`#1f293d`), and `rgba(17, 24, 39, 0.6)` backdrop blur.
- Features dynamic acceptance-rate progress rings, difficulty indicators (`Easy` / `Medium` / `Hard` / `Insane`), and problem source tags in `label-code` typography.

### Input Fields & Code Editors
- **Text Inputs:** Dark zinc fills (`#0f172a`), 1px outline (`#1f293d`), placeholder text in muted slate (`#475569`). Focus state highlights border with `#6366f1` and adds a subtle cyan focus ring (`0 0 0 2px rgba(6, 182, 212, 0.2)`).
- **Code Consoles:** Strict `#0a0e17` slate background, line numbers rendered in `JetBrains Mono` slate-600, active code line illuminated with `#1e293b55`.

### Checkboxes & Radios
- Square with 4px border radius (checkbox) or circular (radio), `#1f293d` outline. Selected state fills with `#6366f1` featuring a bright white crisp checkmark icon and `#6366f140` outer glow.

### Interactive Telemetry & Radar Badges
- Hexagonal and pentagonal skill radar widgets rendered with cyan and violet vector paths over a faint concentric background web. Vertices emit glowing pinpoint markers on hover displaying mastery percentiles.
